Prepare an SDK candidate

From a Node ≥22.13 checkout, install workspace dependencies with corepack pnpm install --frozen-lockfile, then run corepack pnpm --filter @phoenix/sdk build and corepack pnpm --filter @phoenix/sdk check:artifact. The build bundles private workspace implementations into one Node ESM entry, rolls up real TypeScript declarations, and includes the GPL license. The check packs the result and exercises ESM/TypeScript imports from a disposable consumer installation, manifest compatibility and event fixtures; it does not publish.

Pack locally using npm pack ./sdk/capability --pack-destination /tmp. Inspect the archive, associated source offer, dependency notices and licence review before any distribution. Do not publish or tag without owner approval. SDK 0.1.0 is a package version, not a declaration of stable 1.0 publication.

Compatibility scope

Legacy v1 manifests omit version fields; explicit v1 manifests set manifest_version: "1" and compatibility.protocol: "1". Historical event samples carry wire 1.0; the current emitter stamps 1.1. No actual second SDK package version, manifest major, or protocol major exists in this checkout. A real upgrade-pair matrix remains an owner-supplied release prerequisite.
