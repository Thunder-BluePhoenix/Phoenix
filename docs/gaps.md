# Gap register

Everything that is **not done, not verified, or decided on someone else's behalf** while building
phases 22–30. One row per gap. A gap is closed by deleting its row in the same change that closes
it, not by rewording it.

How to read the columns:

- **Kind**: `unverified` (built, but not exercised against the real thing), `missing` (in the phase
  scope, not built), `decision` (needs a product/owner call), `limitation` (known, accepted),
  `deviation` (built differently from the phase doc, with the reason).
- **Phase**: the phase whose exit criteria or tasks it touches.
