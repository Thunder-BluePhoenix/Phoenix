# ADR-0018: Fawkes asset format and licence

**Status:** Accepted  
**Date:** 2026-10-03

## Context

Artwork must be original and licence-compatible (PRD v2.0 §17, §25).

## Decision

P0 animations use SVG + CSS animations (small, themeable, easy reduced-motion fallback). Evaluate Rive/Lottie for P1. Fawkes artwork is licensed CC BY-SA 4.0 (one-way compatible with GPL-3.0) with provenance recorded in the licence inventory.

## Consequences

No Codex Pets or Coucou assets are used.
