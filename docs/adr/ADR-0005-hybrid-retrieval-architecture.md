# ADR-0005: Hybrid retrieval architecture

**Status:** Proposed  
**Date:** 2026-10-03

## Context

Memory retrieval will need lexical, vector and graph strategies (Tech Spec §08).

## Decision

Start with lexical retrieval (Phase 28); add vector + rerank (Phase 37) and graph (Phase 38) only when measurably useful.

## Consequences

Deferred until Stage 3.
