## Goal

Personalise Fawkes and tell sources apart at a glance.

## Tasks — parity with Coucou

- [ ] Wardrobe (right-click) and seasonal outfits
- [ ] A colour / mini character per agent and per service
- [ ] Choose which tools and agents appear ("active pills")

## Tasks — Phoenix improvements

- [ ] User-chosen colour per source
- [ ] Outfits as a separate asset pack format so the community can add original ones

## Deliverables

- Outfit asset format + original outfits
- Per-capability "show in Fawkes" setting

## Exit criteria

- [ ] Outfits render in every Fawkes view, including reduced motion

## Notes & risks

- Phoenix uses its own assets; nothing from Coucou's asset list (names, Mochi, sounds, icons, media).
- Any copied or closely translated MIT code keeps its notice and goes in the licence inventory.
- Side effects go through the permission/tool gateway and the audit log; untrusted content is data, never instructions.
- Own assets only.
