## Goal

Provide a registry that treats security, permissions, provenance and licences as first-class — not a blind marketplace.

## Scope

**In scope**

- Manifest validation
- Version compatibility
- Permission + licence metadata
- Health + security reporting

**Out of scope**

- Monetised marketplace

## Tasks

- [ ] Registry index format + validation pipeline
- [ ] Show permissions + data categories before install
- [ ] Licence metadata + GPL compatibility check
- [ ] Security reporting process for capabilities
- [ ] Sandboxing policy for third-party capabilities
- [ ] Release v0.9

## Deliverables

- Capability registry
- v0.9 release

## Exit criteria

- [ ] SDK and core stable for external users (gate v0.9 → v1.0)
