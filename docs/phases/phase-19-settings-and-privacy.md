## Goal

Give users full control over appearance, behaviour, integrations, notifications, privacy and retention.

## Scope

**In scope**

- Settings: PetSettings, CapabilitySettings, PrivacySettings
- Retention + deletion controls
- Telemetry opt-in
- Per-capability permission view

## Tasks

- [ ] PetSettings: appearance, reduced motion, quiet mode, desktop options
- [ ] CapabilitySettings: enable/disable, configure, view permissions + data categories
- [ ] PrivacySettings: retention per data class, delete history, external-AI opt-in
- [ ] Notification preferences
- [ ] Telemetry: off by default, documented
- [ ] Emergency 'disable all capabilities' button

## Deliverables

- Settings UI

## Exit criteria

- [ ] FR-014 satisfied
- [ ] User can revoke any permission and delete any stored data
